# Tài liệu tổng quan và thuyết trình

Kiến trúc User Voice cho **Android, iOS, Flutter, React Native và Web**: gateway dùng chung, client và lifecycle theo nền tảng.

| Tài liệu | Mục đích |
|---|---|
| [Mô tả hệ thống (Word)](user-voice-system.docx) | Bản chỉnh sửa được, 10 trang, giải thích kiến trúc, định danh, phiên, gọi hai chiều, push, readiness và vận hành |
| [Mô tả hệ thống (PDF)](user-voice-system.pdf) | Bản đọc/chia sẻ |
| [Nguồn Markdown](../docs/system-overview.md) | Đọc trực tiếp trên GitHub, có sơ đồ Mermaid chi tiết |
| [Thuyết trình (PowerPoint)](user-voice-overview.pptx) | 16 slide, sơ đồ/bảng/text chỉnh sửa được, có speaker notes |
| [Slide (PDF)](user-voice-overview.pdf) | Xem trước hoặc trình chiếu không cần PowerPoint |
| [Lời dẫn thuyết trình](speaker-notes.md) | Gợi ý trình bày từng slide |

Bộ slide phù hợp phần giới thiệu khoảng 15–20 phút; dùng tài liệu mô tả khi cần trao đổi kỹ thuật sâu hơn. Có thể sửa tên ứng dụng và bố cục để phù hợp buổi giới thiệu.

Tài liệu phân biệt rõ **Android đã triển khai** với **các client/adapter nền tảng còn cần phát triển**. Không dùng phần kiến trúc mở rộng để công bố đã hỗ trợ/đã nghiệm thu tất cả nền tảng. Các tài liệu không chứa thông tin đăng nhập, định danh hoặc tuyến đang vận hành.
